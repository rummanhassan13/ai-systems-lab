# AI Systems Lab

**Research. Build. Test. Document.**

AI Systems Lab is a public research and engineering workspace by [Rumman Hassan](https://github.com/rummanhassan13) ([website](https://rummanhassan.cv)). It holds the documentation, source code, experiment reports and reproducible examples for small, reliable AI systems: retrieval-augmented generation (RAG), function calling, lightweight agents, workflow automation, evaluation, and safety.

Planning and status live on the public [AI Systems Lab project board](https://github.com/users/rummanhassan13/projects/1).

## Status

Early planning. This repository currently contains the methodology and the experiment report template only. There are no experiments, results or benchmarks yet, and none are claimed. Ten experiments are planned on the project board; each will be added here only when it has code and a verified write-up.

## Planned research areas

RAG, Agents, Tool Calling, Automations, Evaluations, Safety. See the [project board](https://github.com/users/rummanhassan13/projects/1) for the problem statement and acceptance criteria of each planned experiment.

## Principles

- Small, understandable systems over large frameworks.
- Measure before claiming; publish negative results.
- Pin versions, prompts, datasets and configuration so runs can be reproduced.
- No real personal data, credentials or client content anywhere in this repository.
